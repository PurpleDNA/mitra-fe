# mitra-fe

The customer-facing frontend for **Mitra — the clearinghouse for agentic commerce**.
Landing page now; the client app follows in the same Next.js project.

The engine lives in the sibling repo [`../mitra`](../mitra).

```bash
npm install
npm run dev   # http://localhost:3000
```

Sections, top to bottom: hero (clearing figure) → the problem → what Mitra does
(scroll-driven five functions) → the three checks → clear first (without / with
Mitra) → early access.

Rules for changing it, and why things are built the way they are: [AGENTS.md](AGENTS.md).
